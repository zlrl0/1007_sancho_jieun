# 한영 통합 검색과 PaperQA2 한국어 답변 실험 결과

정리일: 2026-10-05. 논문 12편의 기존 절 단위 조각 862개와 v2 다중논문 질문 30개를 사용했습니다. 원본 조각·정답·생성 답변은 변경하지 않았습니다.

## 결론과 실험의 의미

**앞선 검색 비교에서 한국어 Qwen + 영어 BGE-m3-ko의 RRF 통합이 비교 조건 중 가장 높은 완전 적중@20을 보여, 이 조합으로 한국어 답변 생성 실험을 진행했습니다.** 이번 실험은 그 선택을 답변 생성 단계로 이어가고, 검색 후보와 답변 입력 근거를 늘렸을 때의 변화를 확인한 후속 실험입니다.

기존 20/5에서 25/12로 변경하자, 답변 입력에 필수 논문의 정답 조각이 모두 포함된 문항은 **18→22개**, 최종 인용에 포함된 문항은 **12→17개**로 늘었습니다. 그러나 생성 답변에는 조건 혼합·필수 항목 누락·근거 없는 추가 설명이 남았습니다. **검색에서 유리한 조합을 선택했고 근거 반영도 개선됐지만, 정확한 종합 답변은 추가 개선이 필요하다**는 결론입니다.

## 1. 왜 이 모델 조합을 선택했는가

앞선 실험은 답변 생성 없이 검색만 비교했습니다. 아래는 동일한 30문항에서 최종 고유 조각 20개를 평가한 주요 조건입니다. 조합의 앞은 한국어 질문, 뒤는 영어 질문입니다.

| 검색 조건 | 완전 적중@20 |
|---|---:|
| 한국어 단독 · Qwen | 17/30 (56.7%) |
| 영어 단독 · Qwen | 14/30 (46.7%) |
| 한국어+영어를 한 입력으로 연결 · Qwen | 15/30 (50.0%) |
| Qwen / Qwen · RRF | 19/30 (63.3%) |
| Qwen / 원본 BGE-M3 · RRF | 19/30 (63.3%) |
| Qwen / KURE-v1 · RRF | 20/30 (66.7%) |
| Qwen / BGE-m3-ko · 번갈아 선택 | 20/30 (66.7%) |
| **Qwen / BGE-m3-ko · RRF** | **21/30 (70.0%)** |

선택 조합은 한국어 Qwen 단독보다 4문항, 영어 Qwen 단독보다 7문항 더 완전 적중했습니다. 한영 통합이 검색에서 더 좋았다는 앞선 결과를 근거로 답변 실험에 진입한 것이 맞습니다. 다만 모든 통합 조합이 단일언어보다 좋은 것은 아니며, 이번 데이터와 비교 조건에서의 관찰입니다.

- 한국어 모델: `Qwen/Qwen3-Embedding-4B`
- 영어 모델: `dragonkue/BGE-m3-ko` — 원본 `BAAI/bge-m3`와 구분합니다.
- 추가 임베딩 지시문 없이 dense 검색만 사용했습니다. Sparse/hybrid 결합은 없습니다.
- 근거: [통합 검색 비교](../paperqa2_bilingual_fusion_20261004/RESULTS.md), [Qwen/KURE 추가 비교](../paperqa2_bilingual_fusion_20261004/qwen_kure_rrf/RESULTS.md), [원본 BGE-M3 비교](../paperqa2_bilingual_fusion_20261004/original_bge_m3_rrf/RESULTS.md).

## 2. 답변 생성 구조와 이번 변경

같은 질문의 한국어 버전은 Qwen으로, 영어 버전은 BGE-m3-ko로 각각 검색합니다. 두 목록을 chunk_id 기준으로 합치고 동일 조각의 RRF 점수를 합산합니다. RRF는 동일 가중치의 `1/(60+rank)`이며 동점은 코퍼스 순서입니다. 같은 논문의 서로 다른 조각은 유지합니다.

통합 후보를 PaperQA2 RCS에서 평가·요약한 뒤 관련성 상위 근거 요약을 전달하여 **gpt-4.1-mini가 단일 한국어 답변**을 생성합니다. 언어별 답변 두 개를 생성한 뒤 합치는 구조가 아닙니다. 기존 정답과 정답 근거 표시는 생성 모델에 제공하지 않았습니다.

| 설정 | 기존 20/5 | 이번 25/12 |
|---|---:|---:|
| 언어별 검색 수 | 각 20개 | 각 25개 |
| RRF 통합 후 RCS 입력 조각 수 | 20개 | 25개 |
| `settings.answer.evidence_k` | 20 | 25 |
| `settings.answer.answer_max_sources` | 5 | 12 |
| 답변 언어 | 한국어 | 한국어 |
| 답변 모델 | gpt-4.1-mini | gpt-4.1-mini |

`answer_max_sources=12`는 논문 12편을 보장한다는 뜻이 아니라 답변 입력 근거 요약 개수의 상한입니다. 외부 RRF 후보를 쓰므로 `evidence_retrieval=False`로 내부 재검색을 끄고 실제 25개가 RCS에 전달됐는지 검증했습니다.

기존 무프롬프트 임베딩 벡터를 재사용하고 기존 상위 20개 순위의 재현을 확인했습니다. 추가 임베딩이나 모델 다운로드는 없었습니다. 모델·온도·요약/답변 프롬프트·출력 한도는 유지하고 RCS와 답변은 새로 생성했습니다.

## 3. 단계별 정답 근거 적중 결과

| 단계 | 기존 20/5 | 이번 25/12 | 문항 수 변화 |
|---|---:|---:|---:|
| 통합 검색 후보 | 21/30 (70.0%) | 22/30 (73.3%) | +1 |
| RCS 후 근거 | 21/30 (70.0%) | 22/30 (73.3%) | +1 |
| 최종 답변 입력 근거 | 18/30 (60.0%) | 22/30 (73.3%) | +4 |
| 실제 인용 근거 | 12/30 (40.0%) | 17/30 (56.7%) | +5 |

완전 적중은 **필수 논문마다 지정 정답 chunk_id 또는 alt_chunk_ids가 하나 이상 포함되는 것**입니다. 한 논문에 필요한 세부 근거가 여러 개여도 하나만 맞으면 해당 논문은 적중입니다. 따라서 위 숫자는 모든 세부 정답을 확보하거나 정확히 답한 문항 수가 아닙니다. RCS 후 수치도 요약문이 정답 내용을 정확히 보존했음을 뜻하지 않습니다.

이번 설정에서는 검색 후보에서 확보한 22문항의 논문별 정답 조각 적중이 답변 입력 단계까지 유지됐습니다. 기존 설정에서는 21문항 중 18문항만 유지됐습니다. 인용 단계 적중도 증가했으나 인용 내용을 정확히 설명했는지는 별도 검수가 필요합니다.

## 4. 생성 답변 30문항 AI 검수

두 설정 모두 저장된 답변과 기존 정답·근거 조각을 대조했습니다. PDF 원본의 독립 검증이나 사람 검수가 아니며, 질문·번역·gold도 사람 검수 전입니다.

| AI 질적 판정 | 기존 20/5 | 이번 25/12 | 의미 |
|---|---:|---:|---|
| 충족 | 1 | 1 | 필수 내용 포함, 대조한 근거에서 주요 오류를 발견하지 못함 |
| 핵심 충족·주의 | 6 | 8 | 필수 답은 있으나 설명·요약·인용 등에 수정 사항 있음 |
| 부분 충족 | 4 | 4 | 필수 내용이나 연구별 대응 일부 누락 |
| 오류 포함 | 19 | 17 | 조건·대상 혼동, 근거 없는 추가, 결론 모순 등이 있음 |

추가 설명의 오류도 고려한 판정입니다. 필수 숫자가 있어도 잘못된 주장이 추가되면 오류 포함으로 분류될 수 있습니다. **이 집계를 확정 정답률로 환산하거나 답변 품질의 유의한 향상으로 해석하지 않습니다.**

r25는 CL=Nrf2, BS=Nrf1을 이번 답변에서 구별했습니다. 반면 r03은 ASA 복합 추출물을 아세틸살리실산으로 오인했고, r27은 측정 대상 유전자들을 기준 유전자로 혼동했습니다. r28은 상층액 ELISA 파장이 근거에 있는데도 정보가 없다고 답했습니다. 근거 수를 늘리는 것만으로 이러한 종합 오류가 해결되지는 않았습니다.

지정 gold 외 조각에 동등한 답이 있는 경우도 있으므로 chunk_id 적중과 내용 평가는 따로 봐야 합니다. 기존 파싱의 그림 서술 근사값도 논문 본문 수치와 구별했습니다.

## 5. 비용과 인용 오류

- 이번 실행 완료 호출: 780회 — RCS 750회, 답변 생성 30회.
- 이번 실행 비용 기록: **$0.4181108**. 캐시 할인 미반영 계산값이며 청구서 확정 금액이 아닙니다.
- 출력 한도 도달 호출: 0회.
- 미등록 인용 키: r20의 `pqac-e23e1b` 1종, 생성 원문에 2회 등장.
- 실제 전달 키는 `pqac-e23e1b1b`이며 `ko_02:SEC_none:0009`에 대응합니다. 키 끝부분이 잘려 연결되지 않은 표기 오류입니다. 이것만으로 답변 전체의 정오가 결정되지는 않습니다.
- 생성 답변·인용 채점값은 수정하지 않았습니다. HTML·AI 검수·이번 문서 수정에는 추가 API 호출이 없습니다.

## 6. 확인한 결론과 남은 검증

**확인한 것:** 앞선 검색 비교에서 선택한 한영 통합 조합이 해당 단일언어 대조군보다 높은 검색 적중을 보였고, 이 근거를 PaperQA2에 통합 전달해 단일 한국어 답변을 생성할 수 있었습니다. 25/12에서는 20/5보다 답변 입력·인용의 정답 근거 적중이 증가했습니다.

**남은 것:** 선택 조합의 최종 답변이 단일언어 답변보다 더 정확한지는 같은 조건의 답변 대조가 필요합니다. 앞선 검색 우위를 부정하는 것이 아니라, 검색에서 확인한 우위가 최종 답변에도 이어지는지를 별도로 검증하는 것입니다.

20→25와 5→12를 동시에 바꿨고 RCS·답변도 재생성했으므로 각 설정의 효과와 생성 변동을 분리할 수 없습니다. 30문항은 근거가 겹치고 같은 문항으로 여러 모델을 선택·비교한 탐색적 평가이므로 일반적 모델 우위나 통계적 유의성을 주장하지 않습니다.

현재는 **Qwen/BGE-m3-ko + RRF를 선택한 검색 조합으로 유지하고, 25/12를 근거 누락이 줄어든 후속 설정으로 기록**합니다. 다음 개선의 초점은 연구별 조건을 구분하는 요약·답변과 정답 근거의 사람 검수입니다. 이번 문서 수정으로 추가 실험을 실행하지는 않았습니다.
