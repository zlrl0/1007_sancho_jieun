## 변경한 조건

- Qwen `prompt=""`, `default_prompt_name=None`, `prompts={}`로 설정해 질문 원문만 입력했습니다. `Instruct:`·`Query:` 접두사와 채팅 템플릿을 추가하지 않았습니다.
- 동일 Qwen revision, BF16, SDPA, batch size 1, 정규화, cosine, 동점 순서, 질문·gold를 유지했습니다.
- 기존 문서 벡터는 재사용했습니다. 로컬 모델 설정에 기본 프롬프트가 없음을 확인했습니다.
- 네트워크 다운로드·유료 API·답변 생성 없음. 질문별 @5·10·20 채점을 다시 계산했고 기존 파일 해시 보존을 확인했습니다.
