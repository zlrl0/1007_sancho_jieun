## 방법과 검증

- 정답: `benchmark/gold_45.json`(reviewed: true). 정답 구절을 README의 norm()으로 정규화해 해당 논문 조각에서 찾은 것을 인정 조각으로 삼았습니다. 구절이 어느 조각에도 없는 4문항(q09, q15, q24, q23)은 제외했습니다.
- 질문 언어: 원문은 한국어 29·일본어 4·중국어 12. 중·일 문항의 한국어판과 전체 영어판은 세션에서 작성한 번역이며 사람 검수 전입니다(`inputs/QUESTIONS.md`).
- 임베딩: 네 모델 모두 bfloat16, 배치 1, 프롬프트 없음. 문서 벡터는 기존 저장본(4B·BGE·KURE: multilingual 실험, 8B: 8B 실험)을 해시 검증 후 재사용.
- 단독: 코사인 상위 25개. 통합: 언어별 25개 → RRF 1/(60+순위) → 고유 조각 25개, 동점은 코퍼스 순서.
- 실행 전후 원본 파일 해시 동일. 유료 API 호출 0회. 단일 문서 질문이라 "정답 논문의 정답 조각이 몇 위냐"를 직접 잽니다.
- 41문항의 탐색적 비교이며 사전 기준(3문항) 미만의 차이는 잡음으로 봅니다.
