## 고정 조건과 프롬프트

- Qwen/Qwen3-Embedding-4B, dragonkue/BGE-m3-ko. 기존 문서 862개·v2 30문항·정답·번역·모델 revision·벡터를 재사용했습니다.
- 각 언어 top25 → 동일 가중치 RRF 1/(60+rank) → 최종 25개. 동점은 원본 코퍼스 순서입니다.
- Qwen 프롬프트 문구는 기존 프롬프트 실험과 정확히 같습니다. Query: 뒤 추가 공백 없이 질문을 연결합니다.

```text
Instruct: Given a web search query, retrieve relevant passages that answer the query
Query:{question}
```

- 문서 벡터는 프롬프트 유무 조건 간 동일합니다. 프롬프트는 질문에만 적용했습니다. BGE는 모든 조건에서 무프롬프트입니다.
- A·B는 기존 무프롬프트 비교, C·D는 프롬프트 적용 후 영어 모델 비교입니다.
- FullHit는 모든 필수 논문에서 지정 정답 또는 허용 대체 청크를 찾은 문항 수입니다. 부분 점수는 문항별 필수 논문 적중 비율의 평균입니다.

## 해석과 검증

- A=21/30, B=22/30을 재현했습니다. 합계뿐 아니라 60개 최종 목록의 순서와 모든 저장 지표가 일치했습니다.
- 3개 캐시 × 한영 60개 검색의 top20 순서와 @5·10·20 채점을 기존 저장본과 대조했습니다.
- Qwen 양쪽 캐시의 추론 설정은 프롬프트를 제외하고 동일함을 확인했습니다. 입력·원본 결과·벡터의 실행 전후 SHA-256도 동일합니다.
- 프롬프트 효과는 검색 순위와 RRF 절단 후 결과로 평가해야 합니다. 단독 검색의 개선이 통합 성능 개선을 보장하지 않습니다.
- 하나의 코퍼스와 같은 30문항의 탐색적 비교입니다. 1~2문항 차이로 통계적 우위를 주장하지 않으며, 동률도 일반적인 동등성의 증명은 아닙니다.
- 기존 v2 정답·번역의 사람 검수 대기 상태를 유지합니다. 지정 근거 기준 검색 결과이며 최종 생성 답변의 정확도는 평가하지 않았습니다.
