# 한국어·영어 근거 통합 검색 실험 결과

30문항 × 9조건의 검색·통합만 완료했습니다. RCS, 답변 생성, 유료 API 호출은 하지 않았습니다.

## 방법

- 기존 12편의 절 단위 862개 조각과 v2 다중논문 30문항을 사용했습니다. 원본은 변경하지 않았습니다.
- 임베딩 검색 지시문 없이 원문 질문만 사용했습니다. Qwen 무프롬프트 및 BGE·KURE의 기존 검색 결과를 검증 후 재사용했습니다.
- 연결 조건만 한국어 원문 + 줄바꿈 + 영어 원문을 Qwen으로 새로 임베딩했습니다. 문서 벡터는 같은 Qwen revision의 기존 벡터입니다.
- 각 언어에서 상위 20개 검색 후, 통합 조건은 고유 chunk_id 20개를 선택했습니다. 같은 문서의 서로 다른 조각은 제거하지 않았습니다.
- RRF: 양쪽 1/(60+rank) 합산, 동점은 코퍼스 순서. 번갈아 선택: 한국어부터 시작, 중복 건너뛰고 20개까지 보충.
- Qwen=Qwen/Qwen3-Embedding-4B, KURE=nlpai-lab/KURE-v1, BGE=dragonkue/BGE-m3-ko.
- 완전 적중: 필수 논문마다 primary 또는 alt 정답 조각이 하나 이상 있음. 부분 점수: 문항별 필수 논문 적중 비율의 평균.
- 같은 논문에 정답 근거가 여러 개여도 하나만 맞으면 그 논문 적중입니다. 답변의 모든 세부 항목 충족을 뜻하지 않습니다.

## 해석

완전 적중@20 최고는 Qwen/BGE · RRF이며 21/30입니다. 동률은 동률로 보고합니다.

이는 검색 근거 적중률입니다. 최종 한국어 답변의 정확도와 PaperQA2 RCS 성능은 아직 평가하지 않았습니다.
질문·번역·정답은 사람 검수 전입니다. 문항 간 근거가 겹치고 같은 30문항에서 여러 조건을 비교했으므로 일반적인 우위나 통계적 유의성을 주장하지 않습니다.
번갈아 선택은 한국어 우선, 연결 질문은 한국어 먼저라는 고정 순서의 결과입니다. 반대 순서는 이번 실험 범위에 포함하지 않았습니다.
