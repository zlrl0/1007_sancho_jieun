# Qwen / 원본 BGE-M3 RRF 검색 실험

한국어 Qwen/Qwen3-Embedding-4B + 영어 BAAI/bge-m3. 기존 dragonkue/BGE-m3-ko와 구분한 추가 실험입니다.
기존 v2 다중논문 30문항, 12편·862개 조각을 그대로 사용했습니다. 추가 프롬프트 없이 dense 검색만 수행했습니다.
각 언어 상위 20개 → 동일 가중치 RRF(상수 60) → chunk_id가 고유한 20개. 동점은 코퍼스 순서입니다.
Qwen 한국어 검색은 검증된 무프롬프트 결과를 재사용했고, 원본 BGE-M3로 862개 문서 조각과 영어 질문 30개를 로컬에서 임베딩했습니다.

| 한국어 / 영어 모델 | 완전 적중@20 | 평균 필수 논문 적중률 | 합집합 완전 적중 |
|---|---:|---:|---:|
| Qwen / BGE-m3-ko (이전) | 21/30 (70.0%) | 83.9% | 22/30 |
| Qwen / BGE-M3 (이번) | 19/30 (63.3%) | 78.9% | 21/30 |
