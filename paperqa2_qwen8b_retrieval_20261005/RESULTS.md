# Qwen3-Embedding-8B 검색 비교: 4B 자리를 8B로 교체

정리일: 2026-10-05. 조각 862개와 질문 60개를 Qwen3-Embedding-8B로 로컬 임베딩(1회)한 뒤, [25/25 비교](../paperqa2_bilingual_fusion_k25_20261005/RESULTS.md)와 같은 규칙(언어별 25개 → RRF 60 → 최종 25개)으로 4B 기준치와 비교했습니다. 검색만 수행했고 RCS·답변 생성·유료 API 호출은 없습니다.

## 방법과 검증

- 8B 임베딩: bfloat16, 배치 1, 프롬프트 없음(비교 대상인 4B 무프롬프트 실행과 동일 조건), 정규화 후 float32 저장. indexes/qwen8b/에 벡터와 manifest.
- 4B·BGE-m3-ko 벡터는 기존 저장본을 재사용했고, 새로 계산한 순위의 앞 20개가 기존 저장 검색 결과와 일치함을 확인했습니다.
- 4개 기준 조건(c01·c02·c04·c08)의 최종 25개 목록을 저장된 25/25 실험 결과와 대조해 전부 재현한 뒤 8B만 바꿨습니다.
- 실행 전후 원본 파일 해시가 같습니다. 유료 API 호출 0회.
- 같은 30문항의 탐색적 비교이며 1~2문항 차이는 잡음 범위입니다. 질문·번역·정답은 사람 검수 전입니다.

## 기록과 재실행

- results/n01~n04.json: 문항별 최종 25개와 채점. results/summary.json: 집계·난제 순위표. validation.json, experiment_plan.json.
- 기존 실험 가상환경의 Python으로 run_qwen8b.py 실행. 벡터가 이미 있으면 임베딩을 건너뛰고 순위만 다시 계산합니다.
